# 3P Matrix - content firewall 
3P-Matrix gives you control over third-party traffic in your browser using a simple five-level slider. It is inspired by the classic uMatrix extension but built entirely on Chrome's native Declarative Net Request (DNR) API, which means all filtering happens inside the browser engine itself — no background script reading your traffic, no interception, no data leaving your device.

The idea is straightforward: most privacy and security problems on the web come from third-party scripts and frames that load silently in the background when you visit a page. Trackers, fingerprinting scripts, ad networks, and malicious injections all arrive this way. 3P-Matrix-lite lets you decide how much of that you allow, and makes it easy to dial it back when something breaks.

3P-Matrix-lite has a killer feature called LOCK PROTECTION (the padlock), when you enable this, the next time you surf to this website the CHOSEN PROTECTION LEVEL WILL BE APPLIED AUTOMATICALLY!

HOW 3P-MATRX-LITE WORKS

When you install the extension, it starts in Easy mode — allow all, which applies no restrictions and lets you observe the default browsing experience. From there you move the slider right to increase protection.

Level 1 — Allow all. 
At first start this extension uses Easy Mode (allow all) as startup mode. You can change the startup mode by clicking on the one (1) in the green rounded square/rectangle in the upper right corner.

Level 2 — Mild protection. 
This mode ads 11 security protections. It uses a build-in whitelist to allow 3p-frames from payment services, video embeds and captcha's. This mode increases security but works  well on all websites.

Level 3 — Medium protection. 
This mode ads (on top of the above 11) 5 additional first-party protections and adds third-party script and frame blocking of domains outside the safer-regions. The safer-regions is a Top Level Domain list automatically determined based on your browser language settings.

Level 4 —High mode. 
On top of the 16 protections it blocks ALL third-party scripts and frames EXCEPT domains with CDN (Content Delivey Network) in name. This mode reduces third-party risk considerably, but works well on 90% of the adult websites (without tweaking).

Level 5 — Strict mode.
This is the strictest setting. All third-party scripts and frames are blocked. Only domains you have explicitly added to your domain whitelist are allowed through. Use this when you want maximum control and are prepared to whitelist what you need.

NOTICE
The scripting permission is used only to register the extension’s own bundled content scripts that implement its security protections: blocking fake payment-handler and protocol-handler registration, alert/confirm dialog spam, ClickFix clipboard hijacking, eval() on high-risk sites, obfuscated eval, and NFC access. The scripts are registered or removed depending on the protection level and the user’s settings. No remote code is loaded or executed, and no page data is read or sent anywhere.

SUGGESTED USE
The default startup level is 2. Choose for random surfing protection level 3. When surfing to dodgy websites lock the level to 4, alternatively lock protection level to 1 for important websites.
After some weeks you can increaase startup level to 3.

Level 5 was only added for hard core uMatrix users (I never used it when I had uMatrix installed)
